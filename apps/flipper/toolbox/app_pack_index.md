# Flipper Toolbox App Index

## Core app buckets

- IR Manager
  - Learn/save your own remotes
  - Group by room/device
- NFC Journal
  - Keep authorized tag inventory
  - Record notes and locations
- RFID Notebook
  - Log card IDs you own
- Sub-GHz Planner
  - Save region notes and legal channel plans
- BLE Scanner Logbook
  - Track your own beacons/devices
- GPIO Bench Notes
  - Wiring maps and test checklists
- UART Bridge Sessions
  - Command logs with ESP32

## Pairing ideas with ESP32

- Flipper GPIO + ESP32 sensor node status LEDs
- Flipper UART terminal + ESP32 CLI console
- Flipper NFC inventory + ESP32 web dashboard mirror
- Flipper IR learning + ESP32 home-status bridge
