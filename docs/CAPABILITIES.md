# Flipper + ESP32 Capabilities (App Ideas)

This is an app-focused list of practical things you can build with a Flipper Zero + ESP32 setup.

## Device & operations
- Asset labeling and check-in/check-out logs
- Hardware test bench checklists
- Technician field toolkit notes

## Infrared
- Home remote library by room
- IR command naming conventions
- Backup/export of learned remotes

## NFC/RFID/iButton
- Personal tag inventory
- Access token owner mapping
- Lifecycle notes (issued/returned/revoked)

## BLE
- Personal beacon monitoring
- Device presence snapshots
- Signal trend logging for your own devices

## GPIO/UART
- Pin validation scripts
- Serial command interfaces
- Board diagnostics and boot logs

## ESP32 firmware apps
- LED/status heartbeat service
- Sensor polling and logging
- Serial CLI command handlers
- PlatformIO project starters
- MicroPython prototyping loops

## Dashboard & data
- Export logs to JSON/CSV
- Build local dashboards
- Compare baseline vs current readings

## Automation
- Regenerate app catalog from repository
- Validate package before copying to SD/workspace
- Export package to deploy directory
